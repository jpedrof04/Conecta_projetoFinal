Barracred Conecta · CMS

Apresentação da arquitetura do sistema: um site institucional dinâmico com área administrativa, alimentado por banco de dados e totalmente editável pelo cliente.

Ruby on Rails 8 · SQLite · Active Storage

1. Visão geral

O projeto converte o site estático do programa social Barracred Conecta em um sistema com CMS próprio: todo o conteúdo do site (textos, títulos, imagens, carrosséis, equipe, projetos) passou a viver em banco de dados e pode ser editado por uma área administrativa com login, no mesmo visual da marca.

🏗️ Site estático (HTML/CSS/JS) → 🗄️ Banco de dados (SQLite) → 🌐 Site dinâmico (Rails) → 🔐 Admin (login)

🎯 Objetivo

Permitir que a equipe atualize fotos, textos, títulos e carrosséis sem deformar o layout e sem mexer em código.

🗂️ Stack

Ruby 3.4 + Rails 8, banco SQLite, uploads com Active Storage, HTML/ERB + CSS original do site, testes com Minitest.

✅ Estado

CMS funcional, front dinâmico no ar, 63 itens de conteúdo semeados com as fotos originais e 38 testes passando.

7. Área administrativa

  • Login com senha criptografada (bcrypt) e sessão por cookie.
  • Páginas / Seções: seções agrupadas com thumbnail, edição de título/subtítulo/texto/imagem/ordem e botão "＋ Adicionar" por seção (para incluir fotos em carrosséis).
  • Alunos / Professores: CRUD com foto e status ativo/inativo.
  • Projetos: capa + galeria múltipla.
  • Layout com a identidade visual da marca (verde Barracred, Poppins, glass cards).
📌 Login padrão: admin@barracredconecta.com.br / barracred123

8. Como rodar

cd cms
bundle install
bin/rails db:migrate          # cria as tabelas
bin/rails db:seed             # cria admin + layout padrão (fotos do front)
bin/rails server              # sobe em http://localhost:3000

Recriar do zero

bin/rails db:seed:replant

Apaga e recria o banco com o layout padrão.

Rodar testes

bin/rails test

38 testes: autenticação, alunos, professores, projetos e conteúdo.

Uploads

Fotos ficam em cms/storage/ via Active Storage. No futuro, trocar por S3/Cloud é só configurar o service.
